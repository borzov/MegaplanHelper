# История изменений

Все значимые изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
проект придерживается [Семантического версионирования](https://semver.org/lang/ru/).

## [Не выпущено]

### Добавлено
- Вкладка «Задачи» во всплывающем окне приложения — показывает задачи, в которых пользователь участвует (ответственный, автор, аудитор или соисполнитель)
- Сортировка задач: по последнему обновлению (по умолчанию), по дате создания, по дате последнего комментария
- Фильтр по статусу задач: «Активные» (по умолчанию) или «Все»
- Поиск по названию задачи и имени ответственного с дебаунсом
- Группировка задач по периодам: «Сегодня», «Вчера», «На этой неделе», «Ранее»
- Аватары ответственных загружаются через общий кэш (1 ч TTL, лимит диска 100 МБ)
- Бейдж непрочитанных комментариев у задачи
- Цветовая индикация статуса: активные/просроченные/завершённые/отменённые
- Затемнение посещённых задач (открытых в браузере хотя бы раз) — по аналогии с уведомлениями
- Клик по задаче открывает её карточку в браузере по адресу `https://{domain}/task/{id}/card/`
- Сегментный переключатель «Уведомления / Задачи» в общей шапке попапа
- Параллельная загрузка уведомлений и задач одним тиком RefreshScheduler (60 с)
- Сохранение настроек сортировки и фильтра задач между запусками приложения

### Безопасность
- Добавлена защита от вредоносных данных при сохранении изображений пользователей
- Добавлена защита от слишком больших уведомлений, которые могли замедлить работу приложения
- Добавлена защита от загрузки слишком больших аватаров (максимум 1MB)
- Добавлена защита от некорректных временных меток, которые могли приводить к сбоям
- Добавлен unit-тест для защиты от XSS-атак через HTML entities
- Добавлена защита от ReDoS (Regular Expression Denial of Service) атак через ленивые квантификаторы в регулярных выражениях
- Добавлена валидация домена при авторизации — блокируются небезопасные адреса (localhost, внутренние сети, metadata endpoints)

### Изменено
- Улучшена обработка ошибок при работе с кэшем аватаров — теперь все ошибки логируются для диагностики
- Добавлены таймауты на загрузку аватаров (10 секунд на запрос, 30 секунд на весь процесс)
- Добавлено ограничение на количество одновременных загрузок аватаров (максимум 5)
- Оптимизирована работа с кэшем информации о пользователях — снижено потребление памяти
- Устранено дублирование данных между AppState и ViewModels — улучшена производительность и снижено потребление памяти
- Удален неиспользуемый код для повышения читаемости и поддерживаемости проекта
- Оптимизирован поиск заблокированных IP-адресов — используется Set вместо массива для мгновенного поиска
- Устранено дублирование кода при извлечении информации о пользователях из уведомлений
- Размеры окна настроек вынесены в константы для единообразия и упрощения поддержки
- Добавлено детальное логирование ошибок при работе с Keychain для улучшения диагностики
- Оптимизирована производительность группировки уведомлений — Calendar.current теперь кэшируется
- Добавлен автоматический контроль размера кэша аватаров — при превышении 100 МБ старые файлы удаляются автоматически
- Улучшена архитектура кода — логика сертификатов и моделей данных вынесена в отдельные модули
- Централизованы настройки кэша и безопасности — упрощена поддержка и настройка приложения

### Исправлено
- Исправлена утечка памяти при запуске приложения — устранено дублирование объектов в памяти
- Исправлена утечка памяти при длительном использовании режима отладки — логи теперь автоматически ограничиваются
- Исправлена потенциальная проблема с сохранением логов, которая могла приводить к утечке системных ресурсов
- Исправлена потенциальная проблема с потокобезопасностью при работе с иконкой в строке меню

- Исправлена утечка памяти, которая могла замедлять работу приложения при длительном использовании
- Исправлен потенциальный сбой при группировке уведомлений по неделям
- Исправлена проблема с блокировкой после нескольких неудачных попыток входа

- Отображение количества найденных результатов при активном поиске

- Плавные анимации для всех интерактивных элементов

- Улучшена структура интерфейса для более стабильной работы
- Обновлена локализация на английский и русский языки

## [1.0] - 2025-10-25

### Добавлено
- Первый релиз приложения Megaplan Menu Bar App
- Интеграция с macOS menu bar для уведомлений Megaplan CRM
- Просмотр уведомлений в реальном времени с настраиваемым интервалом обновления
- Авторизация с доменом, логином и паролем
- Автозапуск при старте системы
- Окно настроек с управлением аккаунтом
