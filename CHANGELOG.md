# История изменений

Все значимые изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
проект придерживается [Семантического версионирования](https://semver.org/lang/ru/).

## [Не выпущено]

### Безопасность
- Добавлена валидация URL схемы для защиты от XSS и фишинга (разрешены только http/https)
- Улучшено время жизни кэшированного пароля - очистка сразу после восстановления сессии

### Исправлено
- Исправлен race condition в refresh timer через использование RefreshScheduler actor
- Улучшена обработка ошибок в validateToken с детальным логированием и валидацией ответа

### Изменено
- Оптимизирован поиск по уведомлениям через предварительную обработку текста (SearchableNotification)
- Оптимизировано логирование: добавлен буферизованный вывод с автоматической ротацией файлов (лимит 5MB)
- Кэшированы regex паттерны в NotificationParser для устранения повторной компиляции
- Оптимизация производительности: кэширование JSONDecoder/JSONEncoder в AvatarCacheManager
- Оптимизация производительности: кэширование NSDataDetector/NSPredicate в StringExtensions
- Оптимизация производительности: кэширование Calendar.current в MegaplanNotification
- Оптимизация производительности: кэширование NSRegularExpression в MegaplanAPI
- Устранено дублирование кода в NotificationParser (normalizeURLString, parseNameComponents)
- Устранено дублирование кода в SettingsViewModel (универсальный метод updateSetting)
- Устранено дублирование кода в AppState (applyTokenValidationResult, restoreCachedNotifications)
- Переведены комментарии на русский язык (кроме docstrings)
- Удалены избыточные и очевидные комментарии из кода

## [1.5] - 2026-01-17

### Безопасность
- Улучшена SSRF защита с использованием URLComponents и расширенным списком блокировки
- Добавлена защита от DoS через глубокие certificate chains
- Улучшена атомарность операций Keychain (SecItemUpdate вместо delete+add)
- Добавлена периодическая очистка кэша NotificationManager
- Очистка пароля из временных данных при выходе

### Исправлено
- Исправлен race condition в certificate pinning (потокобезопасный PinningState)
- Исправлена утечка памяти при отмене Task в AppState
- Исправлен потенциальный краш в NotificationGrouper при вычислении начала недели
- Исправлен сброс счётчика brute-force после истечения периода блокировки
- Исправлен workflow для загрузки артефактов в релиз

### Изменено
- Оптимизация HTMLCleaner: кэширование таблицы HTML entities
- Кэширование DateFormatter для улучшения производительности
- Перенос сетевых таймаутов в Constants.NetworkTimeouts
- Улучшенная валидация email с поддержкой символа `+` в адресе
- Добавлен триггер `workflow_dispatch` для ручного запуска сборки в GitHub Actions

## [1.4] - 2026-01-16

### Добавлено
- Скриншоты приложения в README для наглядной документации
- Certificate Pinning с SPKI хэшированием и graceful degradation
- Защита от SSRF (блокировка запросов к внутренним адресам)
- Валидация email через StringExtensions
- Атрибут kSecAttrAccessible для безопасного хранения в Keychain

### Изменено
- Реорганизация скриптов сборки: перемещение в папку `scripts/`
- Скрипт сборки автоматически обновляет build number перед каждой сборкой
- Увеличен период блокировки при brute-force атаках до 15 минут
- Улучшена производительность NotificationGrouper
- Удалены дублирующиеся подписки и методы

### Исправлено
- Исправлена XSS уязвимость в HTMLCleaner (исправлен порядок декодирования)
- Исправлен фокус поля поиска в menu bar окне
- Исправлен force unwrap в AvatarCacheManager

## [1.3] - 2026-01-07

### Добавлено
- Функция поиска по уведомлениям с фильтрацией по названию, описанию и имени автора
- Отображение количества найденных результатов при активном поиске
- Визуальная индикация активного состояния кнопки поиска
- Визуальный эффект нажатия на карточки уведомлений (масштабирование и яркость)
- Визуальная индикация посещённых уведомлений (прозрачность 65%)
- Сохранение состояния посещённых уведомлений в UserDefaults
- Анимация spring для интерактивных элементов
- Новые UI компоненты: EmptyStateView, LoadingStateView, OfflineBannerView, SkeletonView, ToastView
- Автоматизация GitHub Releases через GitHub Actions
- Документация CLAUDE.md для работы с AI-ассистентами

### Изменено
- Поиск активируется при вводе от 2 символов (было 3)
- Полный рефакторинг архитектуры на паттерн MVVM
- ViewModels перемещены в отдельную директорию `ViewModels/`
- Новые сервисы: ErrorRecoveryService, NotificationManager, UserInfoCache, AvatarCacheManager
- Улучшена структура UI компонентов
- Улучшена обработка ошибок и offline режим
- Обновлена локализация (en/ru)
- Обновлён конфиг SwiftLint

## [1.2] - 2025-11-07

### Добавлено
- Автоматическое обновление build number на основе количества git коммитов
- Скрипт `update-build-number.sh` в Build Phase
- Новые ключи локализации для версии и комментариев

### Изменено
- Заменены hardcoded строки на локализованные ключи
- Использование системной локали вместо hardcoded ru_RU
- Рефакторинг длинных методов: разбиты fetchNotifications и loadAvatar
- Вынесена общая логика парсинга для устранения дублирования

### Исправлено
- Исправлено отображение версии приложения в настройках
- Исправлена локализация дат (теперь используется системная локаль)
- Исправлено отображение комментариев в уведомлениях

### Удалено
- Неиспользуемый код: unreadNotificationsCount, preloadUserInfo, AvatarLoadError, fetchUserInfo

## [1.1] - 2025-10-27

### Добавлено
- Поддержка universal binary (arm64 и x86_64) для Intel и Apple Silicon Mac
- Иконка приложения со всеми необходимыми размерами
- Подробный README с описанием архитектуры и changelog

### Изменено
- Редизайн окна авторизации с иконкой приложения и описанием
- Улучшена поддержка copy-paste в форме авторизации
- Исправлен размер и отображение иконки в menu bar
- Улучшена структура ресурсов иконок
- Санитизация чувствительных данных в логах API (пароли и токены)
- Уровни логирования: debug в dev, error в release
- Перемещение ресайза изображений в background thread
- Удалены hardcoded ссылки на домен
- Уменьшено количество логов в production

### Исправлено
- Исправлен duplicate configuration ID в project.pbxproj, из-за которого проект не открывался в Xcode

### Безопасность
- Очистка кэшированного пароля из памяти при выходе из аккаунта

## [1.0] - 2025-10-25

### Добавлено
- Первый релиз приложения Megaplan Menu Bar App
- Интеграция с macOS menu bar для уведомлений Megaplan CRM
- Просмотр уведомлений в реальном времени с настраиваемым интервалом обновления
- Авторизация с доменом, логином и паролем
- Автозапуск при старте системы
- Окно настроек с управлением аккаунтом
- Отображение уведомлений с иконками, упоминаниями и счётчиком непрочитанных
- Отметка уведомлений как прочитанных
- Открытие уведомлений в браузере
- Кнопки быстрого доступа к базе знаний, сделкам и задачам (только для админов)
- Логирование API для отладки (только для админов)
- Поддержка русских склонений
- Отображение версии и номера сборки
- Хранение учётных данных в Keychain
- Поддержка macOS 13.0+
