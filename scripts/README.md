# Скрипты сборки

Эта директория содержит скрипты для сборки проекта.

## build-universal.sh

Основной скрипт для создания универсальной сборки macOS приложения (arm64 + x86_64).

### Использование

```bash
./scripts/build-universal.sh
```

Или из корня проекта:

```bash
scripts/build-universal.sh
```

### Функционал

- **Автоматическое обновление build number**: Перед сборкой скрипт автоматически обновляет номер сборки:
  - Использует количество коммитов в git (`git rev-list --count HEAD`)
  - Если git недоступен, использует timestamp
  - Обновляет `CURRENT_PROJECT_VERSION` в `project.pbxproj`
  - Обновляет `CFBundleVersion` в `Info.plist`

- **Проверка Xcode**: Автоматически проверяет и настраивает xcode-select

- **Создание универсального бинарника**: Собирает приложение для обеих архитектур (arm64 и x86_64)

- **Экспорт приложения**: Создает готовое к распространению приложение в `build/export/`

### Результат

После выполнения скрипта приложение будет находиться в:
```
build/export/MegaplanHepler.app
```
