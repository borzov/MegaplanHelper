# Автоматическое обновление номера билда

Скрипт `update-build-number.sh` автоматически обновляет номер билда (build number) на основе количества коммитов в git.

## Как это работает

Скрипт использует количество коммитов в текущей ветке git как build number. Это гарантирует, что каждый коммит будет иметь уникальный номер билда.

Если git недоступен, используется timestamp (Unix time).

## Статус

✅ **Скрипт уже добавлен в проект!** Build Phase "Update Build Number" автоматически запускается при каждой сборке.

## Установка (если нужно добавить вручную)

### Вариант 1: Через Xcode UI

1. Откройте проект в Xcode
2. Выберите проект в навигаторе (самый верхний элемент)
3. Выберите таргет `MegaplanHepler`
4. Перейдите на вкладку **Build Phases**
5. Нажмите **+** в верхнем левом углу и выберите **New Run Script Phase**
6. Перетащите новую фазу вверх, чтобы она была **перед** фазой "Compile Sources"
7. В поле "Shell" вставьте:
   ```bash
   /bin/sh
   ```
8. В поле "Script" вставьте:
   ```bash
   "${SRCROOT}/scripts/update-build-number.sh"
   ```
9. Убедитесь, что галочка "For install builds only" **НЕ** установлена
10. Сохраните проект

### Вариант 2: Через командную строку

Скрипт можно запускать вручную перед сборкой:

```bash
./scripts/update-build-number.sh
```

## Проверка

После добавления скрипта в Build Phases, при каждой сборке в Xcode вы увидите в логах:

```
✅ Build number updated to: 123
```

где 123 - это количество коммитов в вашей ветке.

## Примечания

- Номер билда обновляется автоматически при каждой сборке
- Номер билда основан на количестве коммитов, поэтому он будет увеличиваться с каждым новым коммитом
- Если вы работаете в разных ветках, номера билдов могут отличаться
